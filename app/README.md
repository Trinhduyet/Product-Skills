# Admin Settings App

React demo implementing the **Admin Dashboard / System Settings** experience from the Figma community template.

## Stack

- React 19 + TypeScript (strict)
- Vite
- Tailwind CSS v4
- shadcn/ui-style primitives (Radix UI)

## Scripts

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm lint
pnpm build
pnpm preview
```

## Structure

```text
src/
├── app/
├── components/ui/
├── features/settings/
├── config/
└── lib/
```

Settings state is local/mock — suitable for stakeholder demo and developer continuation.
